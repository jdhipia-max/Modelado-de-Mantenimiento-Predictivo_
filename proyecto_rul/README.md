# Mantenimiento predictivo con la Ley de Paris (RUL)

Proyecto de Aula – Ecuaciones Diferenciales.

## Cómo ejecutarlo
1. Instalar Python 3.
2. En esta carpeta: `pip install -r requirements.txt`
3. Ejecutar: `python app.py`
4. Abrir en el navegador: http://127.0.0.1:5000

## Archivos
- `app.py` – backend (Flask): fórmulas de la Ley de Paris, RK4, Torricelli y umbrales AI4I.
- `templates/index.html` – estructura de la página.
- `static/style.css` – diseño.
- `static/app.js` – envía los datos al backend y dibuja las gráficas (Chart.js).
